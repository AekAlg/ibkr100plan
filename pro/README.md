# ميزان | مساعد القرار الاستثماري

نسخة MVP عربية RTL لتحويل خطة الدخل إلى أداة فهم ومحاكاة وقرار أولي.

## التشغيل

من داخل مجلد `pro` شغّل أي خادم ملفات محلي، مثلاً:

```powershell
npx --yes http-server -p 4173
```

ثم افتح `http://localhost:4173`.

## ما الذي يفعله الإصدار الأول؟

- يبني ملفاً أولياً للمستثمر من الهدف، رأس المال، المخاطرة، الأفق، والاستقطاع الأمريكي.
- يعرض محفظة نموذجية منظمة من ثمانية أصول مع وظيفة كل أصل.
- يحسب الدخل السنوي والعائد النقدي المرجح بعد استقطاع STWD الافتراضي.
- يشرح أسباب الاقتراح ومخاطره بدلاً من عرض توصية غامضة.
- يحاكي خفض التوزيعات، هبوط الأسعار، نمو الدخل، وتغير USD/SGD.
- يعرض أثر الدخول على ثلاث دفعات.
- يعمل دون Backend، والبيانات الحالية تخطيطية وليست أسعاراً حية.

## حدود مهمة

هذه الأداة تعليمية وليست نصيحة مالية أو خدمة تنفيذ صفقات. لا تستخدم قراراً فعلياً قبل تحديث السعر، التوزيع، البيانات المالية، الضرائب، سعر الصرف، والعمولات من مصادر موثوقة. يجب فصل مصدر البيانات الحي عن الواجهة قبل إطلاق نسخة عامة.

## الخطوة التالية المقترحة

نقل `assets` إلى ملف JSON أو قاعدة بيانات، ثم إضافة مصدر بيانات موثق مع وقت آخر تحديث، ومحرك مخاطر واختبارات آلية للحسابات قبل إضافة حسابات المستخدمين أو التنبيهات.
